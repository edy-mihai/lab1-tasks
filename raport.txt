Labels (label): Each custom control and form input must be explicitly associated with a <label> or an aria-label so assistive tech can identify its purpose.

Contrast (color-contrast): Adjust the CSS background and foreground colors to meet the strict 4.5:1 or 3:1 ratio requirements for legibility.

Focus Order (tabindex): Ensure the visual order matches the DOM order so interactive elements receive keyboard focus in a logical, expected sequence.

Link Text: Avoid generic text like "click here"; interactive elements must indicate their purpose and state clearly.

Roles (aria-roles): Remove or fix the invalid role values so assistive technologies understand how to interact with those specific HTML nodes.
